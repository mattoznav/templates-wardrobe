# Wardrobe template

A complete starting point for a clothing store: catalogue, sizes, orders and the shop.

| Folder | What it is |
| --- | --- |
| [`website`](website) | Public website |
| [`admin`](admin) | Back office for staff |
| [`customer-app`](customer-app) | Mobile app for customers |
| [`backend`](backend) | API shared by the website, admin and app |

Each folder is a Git submodule with its own repository.

## Getting started

```bash
git clone --recurse-submodules https://github.com/mattoznav/templates-wardrobe.git
```

Part of the [`templates`](https://github.com/mattoznav/templates) collection.
